# Claude Code をクラウドで動かす — Cloud Code 入門

## はじめに

Claude Code は、Anthropic が提供する AI コーディングエージェントです。ターミナルや IDE、デスクトップアプリだけでなく、**クラウド上（ブラウザ）でも実行できる**ようになりました。本記事では、この「クラウド版 Claude Code」の仕組みと使いどころ、そして始め方を解説します。

> ここで言う「Cloud Code」とは、`claude.ai/code` などからブラウザ経由で起動できる Claude Code の実行環境を指します。ローカルに何もインストールせず、隔離されたコンテナ内でエージェントが動作するのが特徴です。

## クラウド版の何が違うのか

従来のローカル実行と比べて、クラウド版には次の特徴があります。

| 項目 | ローカル実行 | クラウド実行 |
| --- | --- | --- |
| 実行場所 | 自分のマシン | クラウド上の隔離コンテナ |
| セットアップ | CLI インストールが必要 | ブラウザだけで完結 |
| リポジトリ | 手元のクローン | セッション開始時に自動クローン |
| ライフサイクル | 常駐 | 非アクティブで自動的に回収される |
| 起動元 | ターミナル / IDE | Web・モバイル・デスクトップ・GitHub Actions など |

### 隔離された使い捨て環境

クラウドセッションは、**隔離されたエフェメラル（ephemeral、使い捨て）なコンテナ**の中で動きます。コンテナ起動時にリポジトリが新しくクローンされ、一定時間操作がないと（またはセッション終了時に）コンテナは回収されます。

このため、**残しておきたい変更は必ずコミットしてプッシュする**必要があります。コンテナが消えれば、コミットされていない作業は失われます。

### ネットワークポリシー

アウトバウンド（外向き）のネットワークアクセスは、環境ごとに設定された**ネットワークポリシー**で制御されます。環境を作成する際にポリシーを選択でき、環境変数やセットアップスクリプトも合わせて構成できます。

## 主なユースケース

クラウド版が特に力を発揮するのは、次のようなシーンです。

- **どこからでも開発を始めたい**: 手元に開発環境がなくても、ブラウザさえあればコード変更を依頼できる。
- **GitHub と連携した自動化**: PR のレビュー対応、CI 失敗の自動修正、Issue からの実装など。
- **並行タスクの分散**: 複数のセッションを立ち上げ、独立したコンテナで別々の作業を進められる。
- **クリーンな環境が欲しい**: セッションごとに新しいクローンから始まるため、ローカルの状態に汚染されない。

## GitHub との連携

クラウド版 Claude Code は GitHub と密に統合されています。

- PR やコメント、CI ステータスの確認・作成
- PR のレビューコメントへの返信
- CI 失敗の調査と自動修正（「PR を監視して」と依頼すると、CI イベントやレビューコメントを受け取って対応）

セッションを PR の活動（コメント・CI・レビュー）に**サブスクライブ**しておくと、イベントが会話に届き、セッションが自動的に起こされて対応を続けられます。ポーリングで待つ必要はありません。

## 始め方

1. **環境を用意する**
   ブラウザで Claude Code のクラウド環境（`claude.ai/code` など）にアクセスします。対象リポジトリ・ネットワークポリシー・環境変数・セットアップスクリプトを設定します。

2. **セッションを開始する**
   リポジトリを指定してセッションを立ち上げると、コンテナが起動しリポジトリが自動クローンされます。

3. **タスクを依頼する**
   「この関数のバグを直して」「テストを追加して」のように、自然言語で作業を依頼します。エージェントがコードを読み、変更し、必要に応じてテストを実行します。

4. **コミット & プッシュ**
   作業が完了したら、コミットして指定ブランチへプッシュします。コンテナは使い捨てなので、**プッシュしない限り成果は残りません**。

## セットアップスクリプトで環境を整える

プロジェクトによっては、テストやリンターを動かすために依存関係のインストールが必要です。クラウドセッションでは **SessionStart フック**やセットアップスクリプトを使って、セッション開始時に自動で環境を整えられます。これにより、Web セッションでもローカルと同じように `npm test` や `lint` が走る状態を作れます。

## 使う上での注意点

- **ディスク容量は固定枠**: 書き込み可能なディスクはセッションごとの固定枠です。`No space left on device` が出たら、不要なビルド成果物やキャッシュを削除すれば、その分がすぐに書き込み可能になります。
- **成果は必ずプッシュ**: 前述の通り、コンテナは回収されるため、残したい変更はコミット & プッシュが必須です。
- **ブラウザは同梱済み**: Chromium がプリインストールされており、Playwright も設定済みです。`playwright install` を実行する必要はありません。

## まとめ

クラウド版 Claude Code は、「ローカル環境に依存せず、どこからでも AI エージェントに開発を任せられる」点が最大の魅力です。隔離された使い捨てコンテナ、GitHub との深い連携、セッション開始時の自動セットアップといった仕組みにより、モバイルからの指示や PR の自動対応など、これまで手間のかかっていた作業を大きく効率化できます。

まずは小さなタスクから、ブラウザ上で Claude Code に依頼してみてください。
