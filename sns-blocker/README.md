# だめ！ — SNS見過ぎ防止 Chrome拡張 🐱

x.com などのSNSを開くと、猫のマスコットが **「だめ！」** と画面いっぱいで止めてくれる Chrome 拡張です。

![猫が「だめ！」と止める](icons/icon128.png)

## できること

- 🚫 **完全ブロック**：登録したサイトを開くと、猫マスコットのオーバーレイでページを覆って止めます。
- ⏱ **5分だけ見る**：どうしても必要なときは一時解除。5分たつと自動でまたブロックします。
- ✏️ **サイトの追加・削除**：拡張アイコンのポップアップから、ブロックするサイトを自由に編集できます。
- 🔄 **設定の同期**：`chrome.storage.sync` に保存するので、同じアカウントのChrome間で設定が同期されます。

## インストール方法（開発者モード）

1. Chrome で `chrome://extensions` を開きます。
2. 右上の **「デベロッパーモード」** をオンにします。
3. **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. この `sns-blocker` フォルダを選択します。
5. ツールバーに猫アイコンが表示されれば完了です。

## 使い方

- **ブロックの追加**：猫アイコンをクリック → 入力欄に `x.com` などを入れて `＋` を押す。
  （`https://x.com/home` のようにURLごと貼り付けてもOK。自動で `x.com` に整えます。）
- **ブロックの解除**：一覧の各サイトの `×` ボタンで削除。
- **初期設定に戻す**：ポップアップ下部の「おすすめの初期設定に戻す」。

### 既定でブロックされるサイト

`x.com` / `twitter.com` / `www.instagram.com` / `www.facebook.com` / `www.tiktok.com` / `www.youtube.com`

（いずれも削除できます。サブドメイン（例 `mobile.twitter.com`）も一致します。）

## しくみ

- `content.js` が全ページに読み込まれ、現在のホスト名をブロックリストと照合します。
- 一致したら `overlay.css` のスタイルで全面オーバーレイを表示し、背後の操作・スクロールを止めます。
- x.com のような SPA（ページ内遷移するサイト）にも、History API をフックして追従します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張の定義（Manifest V3） |
| `storage.js` | ブロックリストの保存・取得・ホスト名の正規化（共通ロジック） |
| `content.js` | ページ上でのブロック判定とオーバーレイ表示 |
| `overlay.css` | 「だめ！」オーバーレイの見た目 |
| `popup.html` / `popup.js` / `popup.css` | サイト追加・削除の設定画面 |
| `icons/` | 猫アイコン（16 / 48 / 128px）と生成スクリプト |

## アイコンの再生成

アイコンは純Pythonスクリプトで生成しています（外部ライブラリ不要）。

```bash
cd icons
python3 make_icons.py
```
