# 📈 投資信託 売り時・買い時サイン（Mac用ローカルWebアプリ）

指定した投資信託の**過去の基準価額**をネットから取得し、値動きをグラフ表示。
テクニカル指標から**買い時・売り時のサイン**を出すMac向けのローカルWebアプリです。

![アプリ画面](docs/screenshot.png)

## できること

- 📊 **値動きのグラフ表示**：基準価額・移動平均線（25日/75日）・ボリンジャーバンドを重ねて表示（拡大・ホバー対応）
- 🟢🔴 **売買サイン**：ゴールデン/デッドクロス、RSIの反転、バンド到達などをチャート上にマーカー表示
- 🎯 **今の総合判断**：複数の指標を合成し「買い時／売り時／中立」をスコア付きで提示
- 🔍 **RSIサブチャート**、直近の売買サイン一覧
- ⏱ **期間切替**（6ヶ月〜全期間）と**人気投信のプリセット**

データ源は投資信託協会の公式「[投信総合検索ライブラリー](https://toushin-lib.fwg.ne.jp/)」の基準価額CSVです。

## 使い方（かんたん・Mac）

1. このフォルダ内の **`run.command`** をダブルクリック。
   - 初回だけ自動でセットアップ（Python仮想環境＋ライブラリ導入）が走ります。
   - 「開発元が未確認」と出たら、`run.command` を右クリック →「開く」を選んでください。
2. 自動でブラウザが開きます（`http://127.0.0.1:5000`）。
3. 人気投信のボタンを押すか、対象ファンドを指定して「分析する」。

> Python 3 が必要です。入っていない場合は [python.org](https://www.python.org/) から入れてください。

### ターミナルから起動する場合

```bash
cd fund-timing
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py          # ブラウザが自動で開きます
```

### ネットなしで画面だけ試す（デモ）

```bash
python app.py --demo   # ダミーデータで動作
```

## 対象ファンドの指定方法

次のいずれかを入力欄に入れます。

- **ISINコードと協会コード**：`JP90C000H1T1,0331418A` のように「カンマ区切り」
- **投信ライブラリーのURL**：[投信総合検索ライブラリー](https://toushin-lib.fwg.ne.jp/)で対象ファンドを検索して開き、
  そのページのURL（`isinCd=...&associFundCd=...` を含む）をそのまま貼り付け

プリセットの人気投信ボタンからも選べます（コードが古くなっている場合はURL貼り付けをご利用ください）。

## サインの見方（テクニカル指標）

| 指標 | 買いサイン | 売りサイン |
| --- | --- | --- |
| 移動平均クロス | ゴールデンクロス（短期が長期を上抜け） | デッドクロス（短期が長期を下抜け） |
| RSI(14) | 売られすぎ(30)から回復 | 買われすぎ(70)から反落 |
| ボリンジャーバンド(20,±2σ) | −2σ到達（割安圏） | +2σ到達（割高圏） |
| 長期線かい離率 | 大きく下方乖離 | 大きく上方乖離 |

総合スコア（−100〜+100）は上記を合算したもので、+30以上で「買い時」、−30以下で「売り時」、その間は「中立」と表示します。
パラメータ（移動平均の日数など）は `signals.py` の先頭で調整できます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `app.py` | Flaskアプリ本体（サーバ・ルーティング・入力解析） |
| `fund_data.py` | 投信協会CSVの取得・整形 |
| `signals.py` | テクニカル指標と売買サインの算出 |
| `funds.py` | 人気投信のプリセット |
| `demo_data.py` | デモ用ダミーデータ生成 |
| `templates/index.html`・`static/` | 画面（HTML/CSS/JS、Plotly.js同梱で配信） |
| `run.command` | Mac用ダブルクリック起動ランチャー |
